# All flags

Every flag of every runtime type, with the types that take it.

**Basics**

| flag | value | what it does |
|---|---|---|
| `-p` | int | Port: The port it listens on (a client: the port of its target). Types: server, client, proxy, cache, storage, dns, idp, db, mqtt, mail, tunnel, metrics, mcp, web. |
| `-s` |  | Start now: Start it as soon as it is made. Types: server, client, proxy, cache, storage, dns, idp, db, mqtt, mail, tunnel, metrics, mcp, web. |
| `-g` (--group) | text | Group: Puts it in a group; a proxy with --backend @group reaches every member. Types: server, client, proxy, cache, storage, dns, mqtt, mail. |
| `--lua` | path | Lua script: A script with the runtime's callbacks, run at start. Types: server, client, proxy, cache, storage, mqtt, mail, mcp. |

**Network**

| flag | value | what it does |
|---|---|---|
| `--bind` | text | Bind address: Bind the port to this address only, such as 127.0.0.1 when only a proxy on this machine should reach it. Types: server, proxy, cache, storage, dns, idp, db, mqtt, mail, tunnel, metrics, mcp, web. |
| `--listen` | text | Unix socket: Listen on a unix socket instead of a port. Types: server, proxy, cache, storage. |
| `--shards` | int | Shards: Worker processes sharing the port: the way one runtime uses more than one core. Types: server, proxy, cache, storage, dns, idp, db, mqtt, mail, mcp, web. |
| `--domain` | list | Names: The names it is reached by through the entrance; empty for its own name. Types: server, proxy, cache, storage, idp, db, mail, tunnel, metrics, mcp, web. |
| `--cpus` | text | CPUs: The CPUs its I/O may run on, as 0-3,6. Types: server, client, proxy, cache, storage, dns, idp, db, mqtt, mail, metrics, mcp, web. |

**TLS**

| flag | value | what it does |
|---|---|---|
| `--tls` |  | TLS: Encrypt its transport: terminate TLS on its port, or dial over it. Types: server, client, proxy, cache, storage, mqtt, mail. |
| `--cert` | path | Certificate: The PEM certificate (chain allowed) a listener presents. Types: server, client, proxy, cache, storage, mqtt, mail. |
| `--key` | path | Key: The PEM key of the certificate. Types: server, client, proxy, cache, storage, mqtt, mail. |
| `--ca` | path | CA: On a listener: require client certificates from this CA (mutual TLS). On a client or proxy: the CA its servers are checked against. Types: server, client, proxy, cache, storage, mqtt. |
| `--acme` | list | ACME names: Names to get a Let's Encrypt certificate for, renewed by itself. Types: server, proxy, cache, storage. |
| `--acme-email` | text | ACME e-mail: The address the CA writes to about the certificate. Types: server, proxy, cache, storage. |

**Limits**

| flag | value | what it does |
|---|---|---|
| `--max-connections` (--max-conn) | int | Max connections: The most clients at once. Types: server, proxy, cache, storage, idp, db, mqtt, mail, mcp, web. |
| `--rate-limit` | int | Rate limit: Messages a second per connection. Types: server, proxy, cache. |
| `--global-rate-limit` | int | Global rate limit: Messages a second over all connections. Types: server, proxy, cache. |
| `--congestion` | text | Congestion control: The kernel's congestion control for its connections, such as bbr, which keeps its rate up under packet loss. Types: server, proxy, cache, storage. |
| `--idle-timeout` | duration | Idle timeout: Close a connection that has received nothing for this long; off unless given. Types: server, proxy, cache, storage. |
| `--read-buffer` | size | Read buffer: How much data may pile up from one connection before it is refused; 1M unless given. Types: server, client, proxy, cache, storage. |
| `--write-buffer` | size | Write buffer: How much unsent data may queue up for one connection before it is dropped; 8M unless given. Types: server, client, proxy, cache, storage, mqtt. |
| `--drain` |  | Drain on stop: Finish what is in flight before stopping. Types: server, proxy, cache, storage. |
| `--reconnect` | int | Reconnect: Reconnect with backoff when the connection drops: the most attempts, 0 for no limit. Types: client. |

**Output**

| flag | value | what it does |
|---|---|---|
| `--log` | path | State log: A file it appends each state change to. Types: server, client, proxy, cache, storage, dns, mqtt, mail, tunnel, metrics, mcp, web. |
| `-w` | path | Message file: A file every received message is written to. Types: server, client. |
| `-b` |  | Print messages: Print every received message. Types: server, client. |
| `-bp` |  | …with name: Print them with the runtime's name before each. Types: server, client. |
| `-bt` |  | …with time: Print them with the time before each. Types: server, client. |
| `-bpt` (-btp) |  | …with time and name: Print them with the time and the name before each. Types: server, client. |

|---|---|---|

| `--send-to` | list | Answer to: Who the built-in path answers: sender, others, master. Types: server. |
| `--udp` |  | UDP: Datagrams instead of a stream. Types: server, client. |
| `--http` | path | Static files: Serve this directory over HTTP. Types: server. |
| `--http-cache` |  | Files in memory: Read the static files into memory at start. Types: server. |
| `--compress` |  | Compressed copies: Serve a file's .br or .gz copy next to it to clients that accept it, unless the copy is older than the file. Types: server, proxy. |
| `--no-inject` |  | Pages as they are: Serve each page exactly as the file holds it, without the WebSocket script. Types: server. |
| `--master-pw` | text | Master password: The password that claims master mode. Types: server. |
| `--no-master-pw` |  | No master password: Take the master password away, which ends master mode. Types: server. |
| `--cache` | text | Cache: A cache runtime its scripts and clients use. Types: server. |
| `--origins` | list | Web origins: Other web origins whose pages may open a WebSocket to it; * for any. Types: server. |
| `-u` (--upstream) | list | Upstreams: Servers it relays to, host:port each. Types: server. |

|---|---|---|
| `--backend` | list | Backends: Where requests go: host:port, https://host, unix:/path, a runtime or @group. None makes it the entrance. Types: proxy. |
| `--protocol` | one of http, tcp | Protocol: HTTP routes by path and name; TCP forwards bytes. Types: proxy. |
| `--strategy` | one of round-robin, random, lua | Strategy: How a backend is picked. Types: proxy. |
| `--auth` | text | Auth: Who may pass: bearer:<file of tokens> or basic:<credentials file>. Types: proxy. |
| `--redirect-https` | text | Redirect to HTTPS: Answer every request with a redirect to HTTPS on this port (443 when empty). Types: proxy. |
| `--backend-timeout` | duration | Backend timeout: How long a backend may take to begin its answer, 2s unless given; 0 waits for ever. Types: proxy. |
| `--retry` | int | Retries: Try a failed request this many times on the next backend. Types: proxy. |
| `--retry-all` |  | Retry POST too: Also retry requests that are not idempotent. Types: proxy. |
