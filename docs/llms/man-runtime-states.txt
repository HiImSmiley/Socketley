# Runtime states

From the manual page socketley(1).

### `created`

The initial state after a runtime is created.

### `running`

The runtime is active and processing I/O.

### `stopped`

The runtime is stopped and can be started again.

### `failed`

The runtime could not start, or its worker died more than five times in ten seconds. **ls** shows the reason. It stays failed until it is started again: fix the cause, then run **socketley start**.
