# Cluster

Daemons on several machines that see each other's runtimes, and the opt-in Raft mode.

Daemons that share a directory form a cluster. Each writes its state there every two seconds; one silent for ten seconds is left out. Then `socketley ls` shows every daemon's runtimes, and a proxy's `@group` backend reaches members wherever they run.

```
# on every machine, the same shared directory
socketley daemon --name node-a --cluster /mnt/cluster
socketley create server api -p 9000 -g api -s
# anywhere in the cluster
socketley create proxy gw -p 8080 --backend @api -s
socketley daemons
```

> Warning: Whoever can write to the cluster directory decides where `@group` traffic goes. Protect it like the control socket.

- More in the manual: **Cluster mode** (man-cluster-mode.txt): The cluster directory is as privileged as the daemons that read it.

- More in the manual: **Raft mode (experimental, opt-in)** (man-cluster-mode.txt): Experimental.

- More in the manual: **Cluster Introspection API** (man-lua-configuration.txt): When the daemon runs in cluster mode ( --cluster ), the socketley.cluster table provides read-only introspection into the full cluster topology.

- More in the manual: **Cluster Event Callbacks** (man-lua-configuration.txt): These optional callbacks fire when the cluster topology changes.

## Service mesh

The proxy's health checks, circuit breaker, deadlines, retries and mTLS are what a service mesh gives each call. `--sidecar` turns on health checks, the circuit breaker, retries and draining in one flag.

- More in the manual: **Health Checks** (man-service-mesh.txt): Active health checks probe backends at a regular interval ( --health-interval ) using either a TCP connect or an HTTP GET ( --health-check ).
- More in the manual: **Circuit Breaker** (man-service-mesh.txt): The circuit breaker prevents cascading failures by tracking consecutive errors per backend.
- More in the manual: **Response Deadline** (man-service-mesh.txt): A backend that accepts connections and then stops answering fails no check.
- More in the manual: **Request Framing** (man-service-mesh.txt): In HTTP mode the proxy is strict about how a request's header block is framed.
- More in the manual: **Retries** (man-service-mesh.txt): When --retry is set, failed requests are automatically retried on the next backend in the load balancer pool.
- More in the manual: **mTLS** (man-service-mesh.txt): Both legs can be encrypted.
- More in the manual: **Sidecar Deployment** (man-service-mesh.txt): The --sidecar flag enables a production-ready set of defaults: TCP health checks, a circuit breaker (threshold 5, timeout 30s), 2 retries, and graceful drain.
