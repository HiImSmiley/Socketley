# mcp runtime

A Model Context Protocol server: the tools, resources and prompts its script declares, for AI clients

An **mcp** runtime is a Model Context Protocol server: an AI client such as Claude Code gets the tools, resources and prompts its Lua script declares.

```
printf 'claude %s\nops %s admin\n' "$(openssl rand -hex 16)" "$(openssl rand -hex 16)" > /etc/socketley/mcp.keys
socketley create mcp shop -p 9600 --keys /etc/socketley/mcp.keys \
    --lua shop.lua --tools daemon --instructions "Ask about the shop's orders." -s
claude mcp add --transport http shop http://127.0.0.1:9600/mcp \
    --header "Authorization: Bearer <claude's secret>"
```

The script declares what is offered:

```
mcp.tool{
    name = "order_status",
    description = "The state of one order: paid, sent or unknown.",
    read_only = true,
    input = { type = "object", properties = { id = { type = "string" } }, required = { "id" } },
    -- the handler and the rest: examples/mcp/shop.lua in the repository
}
```

## What it does

- **Your tools in Lua**: Tools, resources and prompts from the script; `--instructions` says what the server is for.
- **The daemon as tools**: `--tools daemon` lists runtimes for any key; an admin key may start and stop them.
- **Streamable HTTP**: At `/mcp`, one JSON-RPC message per POST, stateless; revision 2026-07-28, and 2025-11-25, 2025-06-18, 2025-03-26.
- **Who may ask**: `--keys`, OAuth sign-in with `--idp`, or `--anonymous` on a local-only port.

## Works with

The entrance [proxy](rt-proxy.txt) terminates TLS in front of it. An [idp](rt-idp.txt) signs people in; its `admins` are admins here.

## Flags

Every flag a mcp runtime takes, by group.

**Basics**

| flag | value | what it does |
|---|---|---|
| `-p` | int | Port: The port it listens on (a client: the port of its target). |
| `-s` |  | Start now: Start it as soon as it is made. |
| `--lua` | path | Lua script: A script with the runtime's callbacks, run at start. |

**Network**

| flag | value | what it does |
|---|---|---|
| `--bind` | text | Bind address: Bind the port to this address only, such as 127.0.0.1 when only a proxy on this machine should reach it. |
| `--shards` | int | Shards: Worker processes sharing the port: the way one runtime uses more than one core. |
| `--domain` | list | Names: The names it is reached by through the entrance; empty for its own name. |
| `--cpus` | text | CPUs: The CPUs its I/O may run on, as 0-3,6. |

**Limits**

| flag | value | what it does |
|---|---|---|
| `--max-connections` (--max-conn) | int | Max connections: The most clients at once. |

**Output**

| flag | value | what it does |
|---|---|---|
| `--log` | path | State log: A file it appends each state change to. |

**MCP**

| flag | value | what it does |
|---|---|---|
| `--keys` | path | Keys: The keys that may call it, one per line: name and secret, plus admin for a key that may change the daemon. |
| `--anonymous` |  | Anonymous: Anyone may call it without a key; only for a port no other machine can reach. |
| `--origins` | list | Origins: The web origins a browser may call it from, or * for any. |
| `--tools` | one of none, daemon | Daemon tools: This daemon's runtimes as tools: listed and read by every key, started and stopped by an admin's. |
| `--instructions` | text | Instructions: What a client is told the server is for. |
| `--idp` | text | Identity provider: The idp runtime whose people sign in, by an access token for https://<first name>/mcp. |
| `--idp-audience` | list | Token clients: The idp's clients whose own access tokens it takes as well. |
