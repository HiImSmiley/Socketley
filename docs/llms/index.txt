# socketley

One Linux daemon and CLI that runs your servers, proxies, caches, storage, databases, DNS, sign-in, MQTT, mail, metrics, tunnels and MCP: each a runtime made with one command.

```
curl -fsSL https://raw.githubusercontent.com/HiImSmiley/Socketley/main/install.sh | sudo sh
socketley create cache store -p 6379 -s          # a Redis-compatible cache
socketley create server api -p 9000 --lua api.lua -s
socketley create proxy edge -p 8080 --backend api -s
socketley ls
```

## What it is

socketley is one binary. As `socketley daemon` it runs **runtimes**: network services, each made with one command and each in its own worker process on an io_uring event loop. Anything else you type is the CLI that talks to that daemon, as `docker` talks to `dockerd`.

A runtime has a type, which decides what it speaks, and a name, by which others reach it (`--backend api`). Every type is created, started and removed the same way.

## The runtimes

- [cache](rt-cache.txt): In-memory store on the Redis protocol: strings, lists, sets, hashes, sorted sets, streams, pub/sub (compared with Redis, Valkey)
- [client](rt-client.txt): Dials a server and holds the connection: TCP, UDP or a unix socket, over TLS, reconnecting (compared with Go, Node.js, Python asyncio, tcpkali, socat)
- [db](rt-db.txt): JSON documents owned by accounts, over HTTP, with indexes, queries, replicas and backups (compared with MongoDB, PocketBase)
- [dns](rt-dns.txt): Authoritative name server for its zones, over UDP and TCP, with DNSSEC and transfers (compared with NSD, Knot)
- [idp](rt-idp.txt): OpenID Connect provider with its own accounts, second factors, app passwords and SSH certificates (compared with Keycloak)
- [mail](rt-mail.txt): Mail server: SMTP, submission, IMAP, POP3, JMAP and webmail, mailboxes in a storage (compared with Postfix and Dovecot)
- [mcp](rt-mcp.txt): A Model Context Protocol server: the tools, resources and prompts its script declares, for AI clients (compared with the MCP Python and TypeScript SDKs)
- [metrics](rt-metrics.txt): Time series for years, answered with PromQL over the Prometheus API, with alert rules and logs (compared with Prometheus, VictoriaMetrics)
- [mqtt](rt-mqtt.txt): MQTT 3.1, 3.1.1 and 5.0 broker on TCP, TLS and WebSocket, with sessions and rules (compared with Mosquitto)
- [proxy](rt-proxy.txt): HTTP and TCP reverse proxy: routes by name and path, health checks, retries, mTLS, FastCGI (compared with HAProxy, nginx)
- [server](rt-server.txt): TCP, UDP, WebSocket and HTTP on one port, answered by Lua or by a built-in path (compared with Node.js (ws, uWebSockets.js), Go, nginx)
- [storage](rt-storage.txt): S3 object storage over a directory, with versioning, replication, a web drive and git (compared with MinIO)
- [sync](rt-sync.txt): One job that carries a directory to a storage, from it, or both ways (compared with rclone, mc)
- [tunnel](rt-tunnel.txt): Makes a machine without an address of its own reachable through an edge it dials (compared with frp)
- [web](rt-web.txt): Static site of files for browsers: a docs site, a blog, a single-page app; caching and compression built in (compared with nginx)

## Benchmarks

Each runtime's headline result against the server people run instead; method and every set are on the [benchmarks](bench.txt) page.

- cache: 3.9× against Redis (GET)
- server: 5.3× against nginx (1 KiB file, keep-alive, 256 connections)
- proxy: 1.2× against HAProxy (HTTP, 1 KiB, keep-alive, 256 connections)
- web: 4.5× against nginx (page 4 KiB, keep-alive, 256 connections)
- dns: 1.2× against NSD (A queries over UDP)
- mqtt: 21.0× against Mosquitto (fan-out: 1 publisher to 50 subscribers, QoS 1, 64 B)
- storage: 18.4× against MinIO (GET 4 KiB, 64 connections)
- db: 2.4× against MongoDB (mixed: 90% reads, 10% writes, 64 clients)
- tunnel: 2.3× against frp (throughput, 512 MiB echoed through the tunnel)
- metrics: 2.6× against Prometheus (CPU per sample ingested)
- sync: 2.1× against rclone (first copy, 2000 files of 64 KiB and 50 of 1 MiB)
- idp: 23.5× against Keycloak (refresh token, 256 clients)
- mail: 4.6× against Postfix 3.10.6 + Dovecot (SMTP in, 4 KiB messages, 64 connections, 10 a connection)
- mcp: 26.0× against MCP Python SDK 2.3.0 (uvicorn 0.54.0) (tools/call add(a, b), 64 sessions)
- client: 1.1× against Go (request-answer: 1 connection, 64 B each way)
