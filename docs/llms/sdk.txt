# C++ SDK

Control a daemon, embed the engine, or attach a process of your own to a daemon.

The C++ SDK in `sdk/include/linux/socketley/` has three tiers. Examples are in `sdk/examples`, and the test suite builds each one.

Socketley ships a modular C++ SDK in three tiers, in **sdk/include/linux/socketley/**. Tiers 1 and 3 are self-contained, header-only files. Copy them anywhere and compile with **g++ -std=c++17**; no library is needed. Tier 2 must be built from source.

| Tier | Header | Use Case | Dependencies |
|---|---|---|---|
| 1 | socketley/control.h | Control a running daemon | None (POSIX) |
| 2 | socketley/{server,cache,proxy,client}.h | Embed the full engine | libsocketley_sdk.a |
| 3 | socketley/attach.h | Register with a daemon | None (Tier 1) |

- More in the manual: **Tier 1: Daemon Control (header-only)** (man-c-sdk.txt): socketley/control.h gives a program full control over a running daemon.
- More in the manual: **Tier 2: Embed Engine (build from source)** (man-c-sdk.txt): Tier 2 embeds the full io_uring event loop and a runtime of any type in your own binary.
- More in the manual: **The C Interface (any language)** (man-c-sdk.txt): socketley/capi.h is plain C and carries nothing of the engine, so any language that can call C can use it.
- More in the manual: **Rust** (man-c-sdk.txt): The crate in sdk/rust wraps the C interface; set SOCKETLEY_LIB_DIR to build against a checkout.
- More in the manual: **Node** (man-c-sdk.txt): The package in sdk/node wraps the C interface.
- More in the manual: **Cross-Platform SDK (Windows / macOS)** (man-c-sdk.txt): The runtimes are Linux only, with or without the daemon, because the engine is built on io_uring.
- More in the manual: **Tier 3: Daemon Attach (header-only)** (man-c-sdk.txt): socketley/attach.h registers your own process as a runtime with a running daemon.
- More in the manual: **Mixed: Engine + Daemon Attach (Tier 2 + 3)** (man-c-sdk.txt): Embed the full engine for maximum performance, and register with the daemon for fleet monitoring.
