Every script and program in the repository's examples/ and sdk/examples/, with what it does.

- `examples/advanced/blitz-handler.lua`: Sub-server for chess blitz mode -- Similar to rapid-handler but for blitz games
- `examples/advanced/daemon-config.lua`: Daemon configuration file -- Place at /etc/socketley/config.lua (system) or ~/.config/socketley/config.lua (dev) Or set SOCKETLEY_CONFIG=/path/to/config.lua

Each loads it into its own interpreter, so `self` is whichever runtime is running the callback -- which is why every body branches on self.name.

Every callback below runs there; nothing in here is read by the CLI.

- `sdk/examples/projects/jobqueue/worker.cpp`: jobqueue — a worker draining the queue jobd serves. -- Deliberately built on the CROSS-PLATFORM header: cache_client.h is the same file on Linux, Windows and macOS, so this worker compiles unchanged on all three and needs nothing from the repo but that one header. A worker fleet on a different OS than the queue is the normal case, not the exotic one.
