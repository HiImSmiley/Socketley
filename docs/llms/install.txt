# Install

The install script, a Debian package or a build from source; the daemon then runs as a systemd service, and socketley update brings the next release.

socketley runs on Linux 5.19 or newer. The release packages are for amd64; from source it builds on x86_64 and aarch64. Install it one of four ways, join the group, then check it.

## A release package

```
curl -fsSL https://raw.githubusercontent.com/HiImSmiley/Socketley/main/install.sh | sudo sh
```

Installs the newest release's `.deb`, asking before each missing dependency (ffmpeg is offered for the storage runtime's thumbnails and video). Where socketley is installed already, it offers to upgrade or remove it. If the package does not fit the machine, the script stops without changing anything.

| Option | Does |
|---|---|
| `--deb FILE` | Installs a package you have. |
| `--yes` | Takes every default. |
| `--uninstall` | Removes socketley. |

A release has two packages, for Debian, Ubuntu and any other distribution with glibc 2.35 or newer: everything but the C library is linked in, so one build serves them all.

| Package | Holds |
|---|---|
| `socketley_0.2.1_amd64.deb` | The binary, the manual, the interactive help and the systemd service. This is what `install.sh` installs. |
| `socketley-dev_0.2.1_amd64.deb` | The [SDK](sdk.txt): `libsocketley.so`, `socketley/capi.h` and a pkg-config file. Only for programs that run runtimes themselves. |

## Updating

```
socketley update --check      # what is installed, and the newest release
sudo socketley update         # installs the newest release and restarts the service
```

The package is checked against the SHA-256 GitHub keeps of it, installed with apt, and the service restarted, which brings back every runtime that was running. `--list` lists the releases, `--to VERSION` installs one, older or newer, and `--deb FILE` installs a package already on the machine.

A socketley built from a clone is updated by the clone's `bash scripts/update.sh`: it pulls, builds, swaps the binary and restarts, and puts the old binary back if the new one does not come up.

## From source, in one step

```
git clone https://github.com/HiImSmiley/Socketley
cd Socketley
bash scripts/install-from-source.sh
```

Checks the kernel, architecture and compiler (GCC 12 or newer), builds liburing and Release, installs the binary, man page and service, and starts the daemon.

| Option | Does |
|---|---|
| `--dry-run` | Prints every command, runs none. |
| `--uninstall` | Removes what it installed. |
| `--prefix` | Installs elsewhere; only `/usr` gives a system service. |

## From source, by hand

1. Dependencies.

   ```
   sudo apt install build-essential libssl-dev libluajit-5.1-dev git
   ```
2. liburing, if yours is older than 2.7.

   ```
   bash scripts/install-liburing.sh          # liburing >= 2.7, only if yours is older
   ```
3. The third-party archives.

   ```
   ./scripts/build-thirdparty.sh                 # the static archives the tree links, HTTP/3 included
   ```
4. Build.

   ```
   ./scripts/premake5 gmake2
   make -C make config=release_x64 -j$(nproc)
   ```
5. Optionally, install system-wide.

   ```
   sudo bash packaging/install-local.sh            # optional: system-wide, with the service
   ```

Without installing, `./bin/Release/socketley daemon &` starts a development daemon on `/tmp/socketley.sock` with state under your home directory; see [environment & files](env.txt).

## Debian packages of your own

```
bash packaging/build-deb.sh 0.2.1
sudo dpkg -i socketley_0.2.1_amd64.deb
```

Run it in a tree prepared as above (`premake5 gmake2`): it builds Release from clean, for this machine's architecture, and writes `socketley-dev` beside it. A package built on a newer distribution can need a newer glibc than an older one has, so build on the oldest one you install to.

## Join the socketley group

```
sudo usermod -aG socketley $USER
```

Only root and the `socketley` group reach the installed daemon; anyone else silently gets a private daemon of their own. Log in again after joining.

## Check it

```
systemctl status socketley
socketley ls
socketley --help          # the interactive help
man socketley
```
