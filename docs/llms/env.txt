# Environment & files

The variables the daemon and the CLI read, and where everything lives on disk.

- More in the manual: **Environment** (man-environment.txt): All of these variables are optional.

- More in the manual: **System Mode (installed via package)** (man-files.txt): /usr/bin/socketley # The socketley binary.
- More in the manual: **Development Mode (no system install)** (man-files.txt): /tmp/socketley.sock # The Unix domain socket for daemon IPC.
- More in the manual: **The IPC socket** (man-files.txt): Every socketley command travels over the socket above, and through it a client can reach everything the daemon can do.
- More in the manual: **Where state lives** (man-files.txt): The two directories above are where a daemon's runtimes live when the daemon serves the default socket.
- More in the manual: **Daemon Configuration** (man-files.txt): The daemon configuration file is a Lua script that sets a daemon table: daemon = { name = "node1", -- this daemon's name in a cluster cluster = "/shared/dir", -- cluster directory; needs name log_leve

- More in the manual: **State persistence** (man-state-persistence.txt): The daemon persists runtime configurations as JSON files.
