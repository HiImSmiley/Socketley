# metrics runtime

Time series for years, answered with PromQL over the Prometheus API, with alert rules and logs

A **metrics** runtime keeps years of what socketley and nearby machines measure. It answers PromQL over the Prometheus HTTP API, so Grafana reads it as a Prometheus.

```
socketley create metrics metrics -p 9090 --scrape /etc/socketley/targets -s
socketley metrics query 'rate(socketley_runtime_messages_total[5m])'
socketley metrics query_range 'up' --start -6h --step 5m
```

## What it does

- **Collects**: This daemon's series with no setup; `--scrape` targets; remote write with `--receive`.
- **Stores compactly**: One to three bytes a sample, with coarser tiers (`--downsample`) for long ranges.
- **Stays bounded**: `--keep` limits age, `--max-series` cardinality; `--durable` loses nothing in a crash.
- **Alerts**: `--rules` in Prometheus's format, sent by webhook, mail or events (`--notify`).
- **Logs**: `--logs` keeps the daemon's log lines and answers LogQL as Loki does.
- **Archives**: `--archive` copies old blocks to an S3 bucket.

## Works with

The dashboard draws its history from it. A [storage](rt-storage.txt) runtime can hold its archive.

## Flags

Every flag a metrics runtime takes, by group.

**Basics**

| flag | value | what it does |
|---|---|---|
| `-p` | int | Port: The port it listens on (a client: the port of its target). |
| `-s` |  | Start now: Start it as soon as it is made. |

**Network**

| flag | value | what it does |
|---|---|---|
| `--bind` | text | Bind address: Bind the port to this address only, such as 127.0.0.1 when only a proxy on this machine should reach it. |
| `--domain` | list | Names: The names it is reached by through the entrance; empty for its own name. |
| `--cpus` | text | CPUs: The CPUs its I/O may run on, as 0-3,6. |

**Output**

| flag | value | what it does |
|---|---|---|
| `--log` | path | State log: A file it appends each state change to. |

**Metrics**

| flag | value | what it does |
|---|---|---|
| `--scrape` | path | Scrape: The targets it scrapes, a line each: name url, then every=, timeout= or labels. |
| `--every` | duration | Every: How often a sample is taken; a target's every= takes the place of it. |
| `--keep` | duration | Keep: How long the raw samples are kept. |
| `--downsample` | text | Tiers: Coarser tiers kept for longer, as step:keep pairs separated by commas, or none. |
| `--max-series` | int | Max series: The most series it keeps; a new one past it is refused and counted. |
| `--durable` |  | Durable: Log every sample as it comes, so a crash loses none. |
| `--no-local` |  | No local feed: Leave this daemon's own series out. |
| `--keys` | path | Keys: Service keys Grafana or a script sends as Bearer or Basic, one name and secret per line. |
| `--idp` | text | Identity provider: The idp runtime whose sign-ins and access tokens may read it. |
| `--idp-audience` | list | Token clients: The idp's clients whose access tokens it takes. |

**Rules**

| flag | value | what it does |
|---|---|---|
| `--rules` | path | Rules: Recording and alerting rules laid over the built-in ones, a rule a line. |
| `--notify` | list | Notify: Where the daemon's own alerts go: webhook, mail and events, or none. |

**Logs**

| flag | value | what it does |
|---|---|---|
| `--logs` |  | Logs: Keep every line the daemon and its runtimes log, queried with LogQL as Grafana queries Loki. |
| `--logs-keep` | duration | Keep logs: How long the log lines are kept. |

**Metrics**

| flag | value | what it does |
|---|---|---|
| `--receive` |  | Take remote_write: Store what a Prometheus or agent sends to /api/v1/write. |

**Archive**

| flag | value | what it does |
|---|---|---|
| `--archive` | text | Archive: An S3 bucket every finished block is copied to, so it outlives --keep. |
| `--archive-credentials` | path | Archive keys: A file with the bucket's access_key and secret_key, in the form sync reads. |

## Benchmarks

A ratio (×) is how many times better socketley did: more per second, or less time, memory or CPU; above 1× socketley is ahead. The range in brackets is the lowest and highest ratio across the passes.

### Scraping 100,000 series a second

Prometheus 2.53.5, VictoriaMetrics 1.112, 7 passes, 2026-11-07, socketley 608e28c6.

| case | socketley | Prometheus | VictoriaMetrics | socketley vs Prometheus | socketley vs VictoriaMetrics |
|---|---|---|---|---|---|
| CPU per sample ingested | 0.29 µs (0.03 cores) | 0.73 µs (0.07 cores) | 1.00 µs (0.10 cores) | 2.59× (2.52–2.62) | 3.56× (3.44–3.63) |
| resident memory | 97.5 MB | 377 MB | 133 MB | 3.87× (3.75–4.00) | 1.36× (1.35–1.40) |
| range query, 5 min of every path | 60.3 ms | 643 ms | 131 ms | 10.53× (6.44–11.65) | 2.19× (1.41–2.89) |

How it was measured: 50 targets × 2000 series, scraped every 1 s by all three at once; all three at once on the same two cores, the targets on four others; each pass a 60 s window. 50 targets of 2,000 series whose values change every second, scraped every second by all three at the same time, data on tmpfs. socketley's CPU includes its daemon's process. The range query asks five minutes of every path's request rate by status code at a 15 s step, the order of the three rotated.
