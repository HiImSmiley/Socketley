A client dials a TCP or UDP peer and keeps the connection. What arrives is printed, saved or handled in Lua.

socketley create client feed -t 10.0.0.5:9000 --reconnect 0 -b -s   # print what arrives, reconnect for ever
socketley send feed "subscribe prices"
socketley create client probe -t unix:/run/app.sock --lua probe.lua -s

What it does

Any target

-t host:port or -t unix:/path; --udp for datagrams.

Verified TLS

--tls, checked against --ca or the system store; no way to skip it.

Reconnects

--reconnect [n] backs off up to 16 seconds; 0 retries for ever.

Output

-b prints messages (-bpt adds name and time); -w file saves them.

Lua

on_connect, on_message, on_disconnect; on_writable paces sending.

Works with

Any server or TCP service. socketley send writes through it from the shell.
