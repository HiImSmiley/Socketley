An mqtt runtime is an MQTT broker (3.1, 3.1.1 and 5.0) for devices, apps and browsers. A client that disconnects keeps its session and the messages it missed until it returns or the session expires.

socketley mqtt passwd /etc/socketley/mqtt.users sensor-17
socketley create mqtt broker --users /etc/socketley/mqtt.users \
    --acl /etc/socketley/mqtt.acl --ws 8083 --persistent on -s
mosquitto_sub -h 127.0.0.1 -u sensor-17 -P secret -t 'home/#'

What it does

Full protocol

QoS 0, 1 and 2, retained messages, wills, shared subscriptions and the 5.0 properties.

TCP, TLS, WebSocket

Port 1883, or 8883 with --tls, and WebSocket on --ws.

Users

A password file (--users), client certificates (--ca), idp tokens, or --anonymous.

Topic rights

Per user in --acl.

Survives restarts

--persistent keeps sessions and retained messages.

Routes

--routes hands matching messages to other runtimes.

Works with

Routes deliver to a cache, db, storage, server or another broker. A storage's events and socketley.mqtt.publish from any script reach its subscribers.
