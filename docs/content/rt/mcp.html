An mcp runtime is a Model Context Protocol server: an AI client such as Claude Code gets the tools, resources and prompts its Lua script declares.

printf 'claude %s\nops %s admin\n' "$(openssl rand -hex 16)" "$(openssl rand -hex 16)" > /etc/socketley/mcp.keys
socketley create mcp shop -p 9600 --keys /etc/socketley/mcp.keys \
    --lua shop.lua --tools daemon --instructions "Ask about the shop's orders." -s
claude mcp add --transport http shop http://127.0.0.1:9600/mcp \
    --header "Authorization: Bearer <claude's secret>"

The script declares what is offered:

mcp.tool{
    name = "order_status",
    description = "The state of one order: paid, sent or unknown.",
    read_only = true,
    input = { type = "object", properties = { id = { type = "string" } }, required = { "id" } },
    -- the handler and the rest: examples/mcp/shop.lua in the repository
}

What it does

Your tools in Lua

Tools, resources and prompts from the script; --instructions says what the server is for.

The daemon as tools

--tools daemon lists runtimes for any key; an admin key may start and stop them.

Streamable HTTP

At /mcp, one JSON-RPC message per POST, stateless; revision 2026-07-28, and 2025-11-25, 2025-06-18, 2025-03-26.

Who may ask

--keys, OAuth sign-in with --idp, or --anonymous on a local-only port.

Works with

The entrance proxy terminates TLS in front of it. An idp signs people in; its admins are admins here.
