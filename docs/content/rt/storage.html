A storage runtime serves the S3 API over one directory, so boto3, the AWS CLI, rclone and other S3 clients keep objects on this machine's disk. It adds a web drive with share links and media.

socketley create storage files -p 9000 --dir /srv/objects \
    --credentials /etc/socketley/storage.creds -s
aws --endpoint-url http://127.0.0.1:9000 s3 mb s3://photos
aws --endpoint-url http://127.0.0.1:9000 s3 cp beach.jpg s3://photos/

What it does

The S3 API

SigV4, multipart uploads, S3 Select; see operations.

Users and policies

Users, IAM, bucket policies, STS.

Keeping versions

Versioning, object lock, lifecycle, tiers.

Copies

Replication to other S3 endpoints, or a cluster of nodes.

On disk

Compression, encryption, and --fsync for durability.

Around the data

Webhooks, bucket websites, quotas.

Web interface

A drive, git repositories, sign-in through an idp.

Works with

sync carries directories into it, mail keeps mailboxes in it, metrics archives to it.
