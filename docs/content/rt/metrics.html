A metrics runtime keeps years of what socketley and nearby machines measure. It answers PromQL over the Prometheus HTTP API, so Grafana reads it as a Prometheus.

socketley create metrics metrics -p 9090 --scrape /etc/socketley/targets -s
socketley metrics query 'rate(socketley_runtime_messages_total[5m])'
socketley metrics query_range 'up' --start -6h --step 5m

What it does

Collects

This daemon's series with no setup; --scrape targets; remote write with --receive.

Stores compactly

One to three bytes a sample, with coarser tiers (--downsample) for long ranges.

Stays bounded

--keep limits age, --max-series cardinality; --durable loses nothing in a crash.

Alerts

--rules in Prometheus's format, sent by webhook, mail or events (--notify).

Logs

--logs keeps the daemon's log lines and answers LogQL as Loki does.

Archives

--archive copies old blocks to an S3 bucket.

Works with

The dashboard draws its history from it. A storage runtime can hold its archive.
