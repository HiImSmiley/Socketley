A sync runtime is one job that carries files between a directory and a storage. Each job has its own line in socketley ls, its own log lines and alert.

socketley create sync photos --dir /srv/photos --storage ui/photos \
    --credentials /etc/socketley/sync.creds --mode out -s
socketley create sync offsite --dir /srv/photos \
    --storage https://files.example.com/photos --credentials /etc/socketley/offsite.creds \
    --every 1h --exclude '*.tmp,.git/*' -s

What it does

Where

--storage: a storage runtime (ui/photos), a host and port, or a URL, bucket last.

Which way

--mode out, in or inout. Several targets only with out.

When

On every change the kernel reports, plus a full walk every --every.

What

All of --dir but the --exclude patterns, under --prefix in the bucket.

Works with

A storage runtime or any S3. A sync opens no port.
