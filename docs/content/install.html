socketley runs on Linux 5.19 or newer, on x86_64 and aarch64. The installed daemon runs as the systemd service socketley; root and members of the socketley group reach it, and anyone else silently gets a private daemon of their own, so join the group and log in again:

sudo usermod -aG socketley $USER

A release package

curl -fsSL https://raw.githubusercontent.com/HiImSmiley/Socketley/main/install.sh | sudo sh

Downloads the newest release .deb and installs it. It lists what the package needs against what is installed, asks before installing each missing dependency (and offers ffmpeg, which the storage runtime's thumbnails and video streams use), and stops, having changed nothing, when the package was built for a newer distribution than yours. Where socketley is installed already it offers to upgrade or remove it. --deb FILE installs a package you have, --yes takes every default, --uninstall removes it.

From source, in one step

git clone https://github.com/HiImSmiley/Socketley
cd Socketley
bash scripts/install-from-source.sh

Checks the kernel, the architecture and the compiler (GCC 12 or newer); installs the build dependencies; builds the liburing this tree needs, since distributions package older ones; builds Release; installs the binary, the man page, the help script and the systemd service; then starts the daemon and asks it for its runtime list before reporting success. --dry-run prints every command and runs none, --uninstall removes exactly what it installed, --prefix moves the install (only /usr gives a system service).

From source, by hand

sudo apt install build-essential libssl-dev libluajit-5.1-dev git
bash scripts/install-liburing.sh          # liburing >= 2.7, only if yours is older
./bin/build-thirdparty.sh                 # the static archives the tree links, HTTP/3 included
./bin/premake5 gmake2
make -C make config=release_x64 -j$(nproc)
sudo bash packaging/install.sh            # optional: system-wide, with the service

The binary is bin/Release/socketley. Run from there without installing, it is a development install: ./bin/Release/socketley daemon & starts a daemon on /tmp/socketley.sock, and state lives under your home directory; see environment & files.

A Debian package of your own

bash packaging/build-deb.sh
sudo apt install ./socketley_*.deb

Build it on the release it is for: its dependencies are read from the binary, so a package built on Ubuntu 24.04 does not install on Debian 12.

Check it

systemctl status socketley
socketley ls
socketley --help          # the interactive help
man socketley
